# Backgrounds

These backgrounds will be used to be displayed behind the generated image.

Backgrounds in the folder [no_shadow](assets/backgrounds/no_shadow) will **not**:
* receive a shadow that is cast on the paper with generated text
* receive a light reflection

This simulates their further distance from the camera in comparison to the paper.

Backgrounds in the folder [with_shadow](assets/backgrounds/with_shadow) will also receive the cast shadow and light reflection.
